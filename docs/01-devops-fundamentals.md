
# 01 - DevOps Fundamentals

## 1. What is DevOps?

DevOps is a combination of Development and Operations.

It focuses on collaboration, automation,
continuous integration, continuous delivery,
and reliable software deployment.

## 2. DevOps Lifecycle

1. Plan
2. Code
3. Build
4. Test
5. Release
6. Deploy
7. Operate
8. Monitor

## 3. Important DevOps Concepts

- Version Control
- Continuous Integration (CI)
- Continuous Deployment (CD)
- Infrastructure Automation
- Monitoring and Logging

## 4. Technologies Used

- Git
- GitHub
- GitHub Actions
- Docker
- Microsoft Azure

## 5. Learning Outcome

Understand the fundamentals of DevOps
and how automation improves software
development and deployment workflows.
